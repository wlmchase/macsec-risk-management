# Risk Management and assessment for a fictional news agency 'The Chronicle'

## Objective

This project focuses on learning the process of risk management and performing a risk assessment.

### Skills Learned

- Risk assessment: Identifying assets, determining threats & vulnerabilities, creating risk register, proposing mitigation strategies in a specified timeline
- Report writing
- Delivering technical information to diverse and non-technical teams

### Tools Used

- NIST SP 800-30
- MITRE ATT&CK Framework
